# HTML Multimedia Player

Proyecto web sencillo que implementa un reproductor multimedia accesible utilizando **HTML5**. Integra reproducción de audio, video con subtítulos y transcripción de texto.

---

## 🚀 Características

- **Reproductor de Audio:** Integración del elemento `<audio>` para reproducir pistas MP3 con controles nativos.
- **Reproductor de Video:** Uso del elemento `<video>` con soporte para archivos MP4.
- **Subtítulos y Accesibilidad:** Implementación del elemento `<track>` para subtítulos en formato WebVTT y atributos `aria-label` para mejor navegabilidad.
- **Transcripción:** Sección dedicada al texto descriptivo del contenido multimedia.
